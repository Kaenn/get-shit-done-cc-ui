  <name>Task 2: Create postinstall download script</name>
  <files>npm/install.js</files>
  <action>
Create install.js following patterns from 11-RESEARCH.md:

1. Platform detection function:
   - Check GSD_UI_PLATFORM env var override first
   - WSL detection via /proc/version parsing (if win32 but has WSL markers, use linux)
   - Map to binary names: linux-x64, darwin-x64, darwin-arm64, win32-x64
   - Exit with helpful message for unsupported platforms (e.g., linux-arm64)

2. Download function with spinner (use ora package):
   - URL: `https://github.com/glennin-codes/get-shit-done-cc-ui/releases/download/v${VERSION}/${binaryName}`
   - Follow redirects (GitHub releases redirect)
   - Show progress with ora spinner
   - Download both binary and .sha256 checksum file

3. Checksum verification:
   - Use crypto.createHash('sha256')
   - Compare with crypto.timingSafeEqual (prevents timing attacks)
   - Throw error on mismatch

4. Write binary to npm/bin/gsd-ui-web (or gsd-ui-web.exe on Windows)
   - Create bin/ directory if needed
   - Set chmod 755 on Unix

5. Error handling per CONTEXT.md:
   - Prompt user to retry on failure (exit 1 with "Retry: npm install")
   - Respect NO_COLOR for output
   - Exit codes: 0=success, 1=error

Dependencies to add to package.json devDependencies: ora (9.0.0), supports-color (9.4.0)
Actually, for postinstall to work, ora must be in regular dependencies (not dev).

<task type="auto">
  <name>Task 3: Create wrapper scripts</name>
  <files>npm/bin/get-shit-done-cc-ui, npm/bin/get-shit-done-cc-ui.cmd</files>
  <action>
Create Unix wrapper script (npm/bin/get-shit-done-cc-ui):

```bash
#!/bin/sh
SCRIPT_DIR="$(cd "$(dirname "$0")" && pwd)"
BINARY="$SCRIPT_DIR/gsd-ui-web"

if [ ! -f "$BINARY" ]; then
  echo "Binary not found. Run 'npm install' to download it."
  echo "Or download manually from https://github.com/glennin-codes/get-shit-done-cc-ui/releases"
  exit 1
fi

exec "$BINARY" "$@"
```

Create Windows wrapper script (npm/bin/get-shit-done-cc-ui.cmd):

```batch
@echo off
setlocal
set "SCRIPT_DIR=%~dp0"
set "BINARY=%SCRIPT_DIR%gsd-ui-web.exe"

if not exist "%BINARY%" (
  echo Binary not found. Run 'npm install' to download it.
  echo Or download manually from https://github.com/glennin-codes/get-shit-done-cc-ui/releases
  exit /b 1
)

"%BINARY%" %*
```

Make Unix script executable: chmod +x npm/bin/get-shit-done-cc-ui
